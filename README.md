# boas-praticas-software

Atividade prática da disciplina **Manutenção e Configuração de Software**.

Sistema simples em Java que calcula a média de duas notas de um aluno e informa
se ele foi aprovado ou reprovado.

## Estrutura

```
src/Sistema.java
```

## Como executar

```bash
javac -d out src/Sistema.java
java -cp out Sistema
```
